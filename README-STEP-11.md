# Meerab’s Collection — Complete Launch Package

Start with `STEP-11-LIVE-LAUNCH.md`.

The package is a consolidated static frontend + Supabase project prepared for
deployment through GitHub and Cloudflare Pages. It does not contain private
account credentials, and it cannot publish to your private accounts automatically.

For the first live launch, use Cash on Delivery while online payment integration
remains a separate server-side implementation.
